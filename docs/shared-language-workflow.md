Approved by Felix on 13 November 2026 (Brisbane) after the falls typo/abbreviation discussion. This supersedes the historical instruction that production incident AI may only make near-identical wording changes. The legacy exact comparator remains available for its original contract/tests, but is not the acceptance gate for a reviewed incident rewrite.

## Coverage and preserved behavior

The same `noteLanguageRules` now reaches both writer and independent reviewer for Fall, Wound and Infection, as well as all five selected targets in Note Generator. It includes the full versioned SCHN reference, confirmed Tx/t/f/CNS/OT meanings, clear anatomical lt/rt expansion, spelling/grammar and natural-prose rules, familiar unit/abbreviation retention and recipient differences. Clear numeric shorthand may remain. Correct clear typos; never guess a medication/dressing identity, silently substitute a product, invent a direct quotation or reclassify a wound.

Local deterministic drafting and assessments remain unchanged. Four report fields, falls six eCase headings, wound/infection paragraph notes, brief recipient summaries, original defaults, independent manual edits and source/pathway ownership remain. GP/NOK wording follows audience relevance; no internal checklist dump in family emails. Significant risks, actual escalation, uncertainty and later findings take precedence over brevity. No new storage, audience, model, key or name protection. This is AI writing assistance, not clinical assessment or guaranteed interpretation.

## Runtime phases

1. Validate authenticated same-origin bounded input, then prepare the canonical documents from the selected incident. The model also receives the original structured incident; source values are untrusted data, never instructions. Canonical text provides field scope/workflow, not a prohibition on correcting its grammar or repetition.
2. Writer returns all seven documents, warnings outside them and exact source/draft references per nonempty output field. Correct spelling, expand clear shorthand, improve flow and deduplicate the same statement; preserve every distinct audience-critical fact and status. Original data remains the primary fact source.
3. Deterministic checks bound shape, text/reference/warning sizes, require exact quotations, reject new numeric tokens per document and preserve six unique ordered falls eCase headings. Existing scoped month/date normalization is reused; doses/ratios/scores are not globally split or converted. Incomplete drafts may have empty fields when canonical has no content there.
4. A separate model call independently checks every field against original structured input and canonical scope. It must reject changed/reassigned values or units, wrong side/site, missing required findings, status upgrades, chronology/source/uncertainty changes, invented normality/products/diagnoses and instruction following. It may approve faithful prose and audience-specific omissions of irrelevant detail. Both calls share the same language policy, one 55-second total budget, store:false, strict JSON and no retries. The browser allows 65 seconds.
5. On approval, return the reviewed documents and external alerts. Textual alerts flag different incident/discovery times, resident-reported account versus unknown mechanism, existing versus new injuries and wound terminology needing clarification. Model warnings can identify other unresolved conflicts. Keep source statements until clarified; do not silently reconcile them. Detection is bounded and not exhaustive.
6. On malformed/unsafe/rejected/provider/timeout/config failure, the server returns a labelled local-template envelope for compatibility with `rewriteFailed:true`; the browser does **not** install it over previous drafts. It preserves existing text/edits/dirty state and reports failure. Explicit local generation remains available with AI unticked. Unreviewed prose cannot enter the client through the new gate. Late results are discarded after input revision changes. Successful regeneration still protects manually edited fields unless Replace all is confirmed.
7. Compare the result to source and verify actual completed actions before Copy. Alerts are outside copied text, retained with the correct pathway and reset when source changes. Refresh/close still loses page-memory work.

## Limits of checks

Source quotation references are anchors, not proof that every claim is supported. A permitted numeric token can still be attached to the wrong finding or unit; omission and semantic correctness rely partly on model review. A reviewer can miss errors or fail to flag an ambiguity. Shared prompts do not train the model or provide universal abbreviation knowledge. Full reference and second review add input-token/latency cost; the bounded request may fail on large incidents. Actual provider quality must be assessed separately from mocks and publication.
